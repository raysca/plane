Infrastructure

Choose your
deployment strategy

Flexible deployment options to match your infrastructure needs. All options support persistent storage for your database and media assets.

External Storage Recommended

For production deployments, we strongly recommend mounting an external persistent disk for your /app/data directory. This ensures your SQLite database and media uploads are safely stored on durable, backup-enabled storage separate from your compute instance.

Single VPS

Recommended

Deploy on a traditional virtual private server with attached block storage. Ideal for most teams.

  • ✓ Attach persistent block storage (DigitalOcean Volumes, AWS EBS, Hetzner Volumes)
  • ✓ Simple backup via disk snapshots
  • ✓ Full control over resources
  • ✓ Predictable monthly pricing
Popular providers:
DigitalOcean Hetzner Linode Vultr
# Mount external volume to /app/data
docker run -d -v /mnt/volume/plane:/app/data plane/lite

PaaS / Serverless

Easy Setup

Deploy to managed platforms with built-in persistent disk support. Zero infrastructure management.

  • ✓ One-click deployments with persistent volumes
  • ✓ Auto-scaling and health checks
  • ✓ SSL certificates included
  • ✓ Managed backups available
Supported platforms:
Railway Render Fly.io Northflank
# Railway with persistent volume
railway volume create plane-data --mount /app/data

Kubernetes

Advanced

Deploy on Kubernetes with PersistentVolumeClaims for enterprise-grade reliability and scaling.

  • ✓ PersistentVolumeClaim for durable storage
  • ✓ Helm chart available
  • ✓ Rolling updates with zero downtime
  • ✓ Works with any storage class
Compatible with:
EKS GKE AKS k3s
# Using PVC for persistent storage
kubectl apply -f plane-lite-pvc.yaml

Homelab / Edge

Self-Hosted

Run on your own hardware with NAS or local storage. Perfect for air-gapped or on-premise deployments.

  • ✓ Mount NAS/SAN volumes for backups
  • ✓ Works on Raspberry Pi (arm64)
  • ✓ Air-gapped deployment supported
  • ✓ No cloud dependencies
Popular setups:
Proxmox TrueNAS Synology Unraid
# Mount NAS share for backups
docker run -d -v /mnt/nas/plane:/app/data plane/lite

Backup Your Data

Plane Lite stores all data in the /app/data directory. Back up this directory regularly to protect your projects.

plane.db SQLite database with all your issues, projects, and settings
uploads/ User-uploaded images, attachments, and media files
config.json Application configuration and workspace settings
Simple Backup Script 
# Daily backup with timestamp
tar -czf "plane-backup-$(date +%Y%m%d).tar.gz" /app/data/

# Sync to S3-compatible storage
aws s3 sync /app/data/ s3://your-bucket/plane-backups/ --delete

# Or use restic for incremental backups
restic -r s3:s3.amazonaws.com/your-bucket backup /app/data/
Deploy

From zero to productive
in 60 seconds

Choose your preferred deployment method. All options are production-ready.

Docker 
# Quick start with Docker
docker run -d \
  --name plane-lite \
  -p 3000:3000 \
  -v plane-data:/app/data \
  plane/lite:latest

# With environment variables
docker run -d \
  --name plane-lite \
  -p 3000:3000 \
  -v plane-data:/app/data \
  -e SECRET_KEY=your-secret-key \
  -e ADMIN_EMAIL=admin@company.com \
  plane/lite:latest
Railway 
# Deploy to Railway with one click
# Or use the CLI:

railway login
railway init
railway up

# Configure persistent storage
railway volume create plane-data
railway link
Fly.io 
# Install Fly CLI and deploy
curl -L https://fly.io/install.sh | sh
fly auth login

# Launch the app
fly launch --image plane/lite:latest

# Create persistent volume
fly volumes create plane_data --size 1
fly deploy
Render 
# render.yaml
services:
  - type: web
    name: plane-lite
    env: docker
    dockerfilePath: ./Dockerfile
    disk:
      name: plane-data
      mountPath: /app/data
      sizeGB: 1
    envVars:
      - key: SECRET_KEY
        generateValue: true
Standalone Binary 
# Download the binary for your platform
# Linux
curl -L https://github.com/makeplane/plane/releases/latest/download/plane-lite-linux-amd64 -o plane-lite
chmod +x plane-lite

# macOS
curl -L https://github.com/makeplane/plane/releases/latest/download/plane-lite-darwin-arm64 -o plane-lite
chmod +x plane-lite

# Run
./plane-lite --port 3000
